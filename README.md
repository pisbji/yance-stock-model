# Yance AI 主线交易模型 V3.0

一个中文选股研究 Skill，适合筛选 A 股和港股、比较自选股，以及复盘前一天给出的交易条件。它围绕三个问题展开：这家公司值得跟踪吗？按当前价格参与，潜在收益能否覆盖风险？成交量和价格走势已经确认了什么？

## 在 Codex 中使用

从本仓库的绿色 **Code** 按钮复制地址并克隆仓库，在仓库根目录启动 Codex。项目内已包含 `.agents/skills/yance-stock-model/`，可以直接输入下面的提示词。

> 用 $yance-stock-model 筛选最近一个已收盘交易日的 A 股二连板，挑出最多两只值得跟踪三板的候选。列出样本范围、Q/B/P/T、次日触发条件，以及什么情况下放弃。

> 用 $yance-stock-model 比较我给出的三只港股。把已触发的买点和仍需等待回踩的候选分开，支撑、触发和失效价都用港币。

> 用 $yance-stock-model 复盘昨天的候选。逐只对照原触发价与失效价，标出哪些已触发，哪些从未触发。若日 K 无法确定先后顺序，请注明。

要在其他项目里调用，可把整个 [yance-stock-model](.agents/skills/yance-stock-model/) 文件夹复制到个人的 `~/.agents/skills/` 目录。参见 [Codex Skills 文档](https://developers.openai.com/codex/skills/)。

## 评分与资格

| 维度 | 要回答的问题 | 权重 |
| --- | --- | ---: |
| Q · 标的质量 | 产业主线、龙头地位、业绩与催化能支撑多少分？有哪些风险需要扣分？ | 45% |
| B · 当前买点 | 入场离失效位多远？潜在上涨空间、估值和流动性是否支持这个价格？ | 25% |
| P · 市场确认度 | 是否停止创新低、出现量能确认、收复关键位、突破前高并守住回踩？ | 30% |

综合分 **T = 0.45Q + 0.25B + 0.30P**。每一档都要求对应门槛同时成立。判档使用未舍入的分数。

| 资格 | Q | B | P | T |
| --- | ---: | ---: | ---: | ---: |
| 核心参与区 | ≥80 | ≥70 | ≥70 | 无额外门槛 |
| 黄金三高 | ≥85 | ≥80 | ≥80 | ≥83 |
| S 级三高 | ≥90 | ≥85 | ≥85 | ≥88 |

**边界例子**　Q=90、B=85、P=85 时，T=87.25，最高资格为黄金三高。若 P 提升到 88，T=88.15，才达到 S 级。买点是否触发还要核对当时的量价结构。

完整的子项分值、风险扣分、三种入场模式和退出规则见[正式评分表](.agents/skills/yance-stock-model/references/model-v3.md)。

## 独立运行计算器

在仓库根目录运行以下命令，仅需 Python 3 标准库。

```bash
python3 .agents/skills/yance-stock-model/scripts/score.py 90 85 88
```

输出包含三个输入分、综合分、最高资格，以及满足分数门槛的入场模式。评估真实股票时，行情、公告和财报由运行 Skill 的助手从可用数据源获取，或由使用者提供。报告会标明数据时点和实际覆盖范围，资料不足的子项标为待核。
